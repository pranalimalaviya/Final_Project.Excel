# Final Project – Customer Transaction Data Analysis

## Project Overview

This project is an Excel-based data analytics project designed to analyze customer transactions, evaluate sales performance, and generate meaningful 
business insights. It combines data organization, Excel formulas, customer segmentation, financial analysis, scenario planning, and dashboard reporting 
in one workbook.

The project demonstrates how Microsoft Excel can be used to transform raw transaction data into useful information for business decision-making.

## Project Objectives

- Organize and analyze customer transaction data.
- Calculate total revenue and average order value.
- Analyze customer purchasing behavior and customer segments.
- Apply Excel date, time, lookup, and conditional formulas.
- Perform what-if and scenario analysis.
- Explore linear regression and sales forecasting concepts.
- Present key performance indicators (KPIs) through an executive dashboard.

## Workbook Structure

The workbook contains four worksheets:

### 1. Row Data

This sheet contains the raw customer transaction dataset used throughout the project.

**Key columns include:**
- Transaction ID
- Transaction Date
- Customer ID and Customer Name
- Product ID and Product Name
- Product Category
- Quantity
- Unit Price
- Payment Method
- Region
- Customer Segment
- Customer Since
- Total Amount

**Purpose:** To maintain the source data for calculations, analysis, and dashboard reporting.

### 2. Analysis

This sheet demonstrates Excel formulas and analytical techniques for extracting insights from the transaction dataset.

**Key topics include:**
- Date and time functions, such as `TODAY()`, `NOW()`, `DATEDIF()`, and `EOMONTH()`
- Customer spending analysis
- Transaction counts and customer tier classification
- Advanced formulas and lookup operations
- Aggregation and conditional calculations

**Purpose:** To apply Excel functions to understand customer behavior and summarize transaction information.

### 3. Visualization

This sheet focuses on what-if analysis and linear regression models.

**Key topics include:**
- Scenario analysis
- Current baseline revenue
- Optimistic growth scenario
- Pessimistic market scenario
- Projected revenue and percentage variance
- Linear regression summary and statistical analysis

**Purpose:** To explore how revenue may change under different assumptions and demonstrate the use of regression analysis.

### 4. Dashboard

This sheet presents an executive summary of the transaction data.

**Key features include:**
- Total Revenue
- Total Transactions
- Average Order Value
- Top Region
- Regional Sales Performance
- Transaction count by region

**Purpose:** To provide a consolidated view of important business metrics for quick interpretation and decision-making.

## Tools and Technologies

- **Microsoft Excel** – Data organization, calculations, analysis, and reporting

- **What-If Analysis** – Revenue scenario planning
